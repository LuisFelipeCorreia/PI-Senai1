#  Develop – SESI Alimentação

Esta branch é destinada à integração e validação de todas as funcionalidades desenvolvidas para o projeto **SESI Alimentação**.

Aqui são reunidas as implementações provenientes das demais branches do projeto, permitindo testes, correções e homologação antes da publicação na branch principal (`main`).

## Objetivo

Centralizar o desenvolvimento do sistema e servir como ambiente de integração entre as diferentes áreas do Projeto Integrador.

## Branches Relacionadas

* Banco de Dados
* Engenharia de Software
* Lógica de Programação
* Redes
* Front-end
* Documentação

## Funcionalidades Integradas

* Sistema de autenticação de usuários
* Catálogo de produtos
* Carrinho de compras
* Gerenciamento de pedidos
* Controle de estoque
* Formas de pagamento
* Painel administrativo
* Integração com banco de dados
* Interface responsiva

## Fluxo de Desenvolvimento

```text
Feature Branches
        ↓
      Develop
        ↓
   Testes e Validação
        ↓
       Main
```

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript
* MySQL
* Git e GitHub
* Docker

## Projeto

O **SESI Alimentação** é uma plataforma web desenvolvida para modernizar o atendimento da cantina escolar por meio de pedidos e pagamentos online, reduzindo filas e proporcionando maior praticidade aos alunos e administradores.
