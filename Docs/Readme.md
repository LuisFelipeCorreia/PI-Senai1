# Documentação de Banco de Dados

Esta pasta contém toda a documentação desenvolvida para a disciplina de **Banco de Dados** do Projeto Integrador **SESI Alimentação**.

## Conteúdo

* **DER (Diagrama Entidade-Relacionamento)** – Modelagem conceitual do banco de dados.
* **Modelo Lógico** – Estrutura relacional das tabelas e relacionamentos.
* **Dicionário de Dados** – Descrição detalhada das entidades, atributos e restrições.
* **Normalização** – Aplicação das formas normais para garantir integridade e reduzir redundâncias.
* **Scripts SQL** – Comandos de criação, manipulação e consulta do banco de dados.
* **Imagens e Diagramas** – Representações visuais produzidas durante a modelagem.

## Banco de Dados Utilizado

* MySQL
* SQL
* BR Modelo

## Objetivo

Projetar e implementar um banco de dados relacional capaz de armazenar e gerenciar informações do sistema **SESI Alimentação**, incluindo alunos, produtos, categorias, pedidos, itens de pedido e formas de pagamento.

## Projeto

O **SESI Alimentação** é uma plataforma web desenvolvida para agilizar o atendimento da cantina escolar por meio de pedidos e pagamentos online, reduzindo filas e melhorando a organização dos serviços oferecidos.
