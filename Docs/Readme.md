# Documentação de Redes

Esta pasta contém toda a documentação desenvolvida na disciplina de **Tecnologias da Informação e Conectividade** para o Projeto Integrador **SESI Alimentação**.

## Conteúdo

* Descrição da Comunicação do Sistema
* Topologia de Rede
* Protocolos Utilizados
* Endereçamento IPv4
* Serviços de Rede
* Segurança da Infraestrutura
* Escalabilidade da Solução
* Diagramas de Rede
* Evidências da Implementação
* Configuração dos Equipamentos

## Tecnologias e Ferramentas

* Cisco Packet Tracer
* IPv4
* TCP/IP
* HTTP
* DNS
* DHCP
* Switch Cisco 2960
* Router Cisco 2911

## Infraestrutura Implementada

* Servidor Web
* Servidor DNS
* Banco de Dados
* Servidor DHCP
* Servidor de Backup
* Servidor de Monitoramento
* Access Point da Escola
* Access Point da Cantina
* Rede Local com Topologia em Estrela

## Objetivo

Planejar e documentar a infraestrutura de rede necessária para o funcionamento do sistema, garantindo comunicação eficiente entre usuários, servidores e serviços da aplicação.

## Projeto

O **SESI Alimentação** é uma plataforma web desenvolvida para permitir que alunos realizem pedidos e pagamentos online na cantina escolar. A infraestrutura de rede documentada nesta pasta garante a conectividade, disponibilidade e segurança necessárias para o correto funcionamento do sistema.
